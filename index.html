geoimagery, the open-source piece

PyPI · MIT

A Python library I published that downloads NAIP aerial imagery for any polygon through Google Earth Engine. Give it a GeoJSON, Shapefile, GeoDataFrame or shapely geometry and it returns RGB GeoTIFFs clipped to each shape. It checks which months exist before downloading, runs inventory and downloads on a thread pool, skips files it already has, and ships type hints.

Usage

Python
import geoimagery as gi

gi.initialize(project="my-gcp-project")

# Which NAIP months exist for each polygon?
inventory = gi.list_available_dates(
    "campuses.geojson",
    start_date="2022-01-01",
    end_date="2024-12-31",
)

# One clipped GeoTIFF per (polygon, month)
gi.download(
    "campuses.geojson",
    dates=inventory,
    output_dir="./naip_output",
    max_workers=5,
)

pip install "geoimagery[all]"

Engineering choices

Idempotent collectionImmutable files with deterministic names, so a retry never duplicates or overwrites data.
History, not snapshotsA late, older record never overwrites a newer state. Malformed rows are quarantined with a reason, never dropped.
All-or-nothing publishingEvery chart, queue and score shares one publication ID and goes live only if all 22 checks pass.
Scored once, in SQLThe model runs in Snowflake from registered weights, on features frozen when a request first becomes eligible.
