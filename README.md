# hpa-code.github.io

Personal website of Hari Acharya, served by GitHub Pages at https://hpa-code.github.io.

A 3D climb up an imaginary Himalayan mountain, with camps for teaching, experience, projects and research. It is a single static page (`index.html`) with no build step. It loads three.js from cdnjs and includes a plain version for anyone who prefers to read without climbing.
