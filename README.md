# hpa-code.github.io

Personal website of Hari Acharya, served by GitHub Pages at https://hpa-code.github.io.

A single static page (`index.html`), no build step. Images load from my public repos via jsDelivr:
[geoimagery](https://github.com/hpa-code/geoimagery) (NAIP imagery, courtesy USDA FSA NAIP) and
[nyc-311-signal](https://github.com/hpa-code/nyc-311-signal) (dashboard screenshots).
